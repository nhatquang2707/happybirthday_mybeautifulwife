# Sinh nhật vợ yêu · 27.07.2026

Website sinh nhật dạng tĩnh, tối ưu để chạy trực tiếp trên GitHub Pages.

## Bật GitHub Pages

Trong repository, mở **Settings → Pages**, chọn:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`

Sau đó bấm **Save**. GitHub sẽ hiển thị đường link công khai khi triển khai xong.
