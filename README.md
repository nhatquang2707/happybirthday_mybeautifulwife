# Sinh nhật vợ yêu · 27.07.2026

Website sinh nhật dạng tĩnh, tối ưu để chạy trực tiếp trên GitHub Pages.

## Chỉnh lời chúc và ảnh

- Mở file `content.js` để sửa lời chúc và chú thích ảnh.
- Tải ảnh lên thư mục chính với đúng tên `photo-1.jpg`, `photo-2.jpg`,
  `photo-3.jpg`, `photo-4.jpg`.
- Hình lịch và nhạc cũng nằm trong thư mục chính để tránh lỗi khi tải lên GitHub.

## Bật GitHub Pages

Trong repository, mở **Settings → Pages**, chọn:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`

Sau đó bấm **Save**. GitHub sẽ hiển thị đường link công khai khi triển khai xong.
